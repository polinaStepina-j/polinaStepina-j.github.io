### Пространственный анализ ВРП регионов РФ (R)
Пространственная эконометрика на данных по субъектам РФ за 2021 год.

**Что сделано:**
- Загрузка и объединение пространственных данных (`sf`) с табличными (`readxl`) по ОКТМО
- Построение трёх типов матриц пространственных весов:
  - **Ферзь 1-го порядка** (бинарная, нормированная по строкам)
  - **K = 5 ближайших соседей** (обратные расстояния)
  - **Ядро Епанечникова** с адаптивной полосой пропускания
- Построение моделей: **OLS**, **SAR** (пространственная авторегрессия), **SEM** (пространственная ошибка)
- Диагностика остатков: тест Бройша–Пагана, тест Морана, LM-тесты Элхорста
- Сравнение моделей по AIC, BIC, LogLik, обоснование выбора лучшей (**SEM-Queen**)

**Стек:** `R`, `sf`, `spdep`, `spatialreg`, `rgeoda`, `tmap`, `lmtest`, `stargazer`
